# Purge Community 1.6.11 验收记录

## 修复范围

- #12：按作者后续纠正的 `/rewind` 重名复现修复，保留原持有者并注册 Purge 备用命令。不是通过停用回退功能或进程级定时轮询来恢复面板。
- #15：读取正确 permission 节点；运行中的实际默认权限优先于磁盘字面量。`inferred` / `unknown` 与 `broken` 分开。CLI JSON/text 退出码一致；零退出码不表示全部已验证。
- 只读状态接口不依赖 connection/session 就绪；服务晚到、替换、父插件重载和卸载均由 Cordis 回收，不留下全局计时器。
- YAML 仅作数据解析，绝不执行 `!!js`。不自动修改用户权限。宿主补丁定义与既有功能保留。
