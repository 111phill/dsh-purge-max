# 1.6.7 安装修复验收

本次只改安装、归档路径兼容和文档；不改变宿主补丁、用户提示词、规则或更新偏好。

- [三平台 CI](https://github.com/kingcharleslzy-ai/dsh-purge/actions/workflows/release.yml)：Linux/macOS/Windows 安装器与维护用例通过；Windows 运行 PowerShell 5.1 和 PowerShell 7 入口测试。Windows 的 POSIX shell 专用测试明确跳过，未把 Windows chmod 当作 POSIX 权限验证。
- 90 项 Node 功能回归、7 项面板测试、原生入口契约、构建一致性、文档版本检查、发行包 smoke 通过。
- 真实 npm 官方元数据：`@dsh-ops/bash-win32-x64@0.2.1` 的身份、版本、发布时间、integrity 与 tarball 校验成功；仅在模拟的精确镜像缺版本错误后，允许一次 scope 级重试。
- Mac 上使用已安装 DSH Desktop 的真实 Electron 和 CLI，在独立 DSH_HOME/profile 中执行下载校验、包迁移、备份与回滚；测试设置保留，备份后新改的提示词也没有被回滚覆盖。未重启真实 DSH，没有修改用户实际 profile。
- Windows 覆盖真实 tar/Node 子进程、中文与空格父目录、参数传递、非零退出、下载失败、环境恢复；不把这些结果宣称为完整 Windows DSH UI/宿主补丁验收。

已知边界：DSH 市场首次安装发生在插件加载前，本版无法接管其错误分类。选择 npm 官方源或使用独立 PowerShell 入口；不要求关闭供应链检查或删除锁文件。Issue #7 保留等待原提交者确认其具体环境。

补充回归：macOS /var 与 /private/var 临时目录路径别名，以及 symlink 入口实际执行；独立安装入口不能静默成功但不工作。1.6.6 初版已被此版取代。

正式产物复核：版本包和稳定别名均通过 SHA256，打包 smoke 通过；用公开 v1.6.7 bootstrap 下载入口完成真实 DSH dry-run，并对公开发行包做隔离安装、备份和回滚。CI：[正式发布](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39096725930)、[主分支检查](https://github.com/kingcharleslzy-ai/dsh-purge/actions/runs/39096723636)。
