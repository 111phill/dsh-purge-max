# Purge Community 1.6.14 验收记录

## 修复范围

- #20：原子替换生成的新 inode 未继承 rwx 权限，使 shell 启动器从0755变成0644。抽出通用 atomic-files 模块，同步/异步替换保留旧权限，复制与回滚保留源文件权限。唯一临时名避免并发冲突；写入、chmod、rename 失败清理临时文件并抛错。
- 官方 CLI 的备份失败现在阻止替换，读取/写入错误设置 report.ok=false。已有备份不覆盖；已识别的旧启动器缺少全部执行位时，按现有读取位补相应执行位，保留其内容和读写权限。
- #19：新增 host-status 与状态接口 host_layout，只读地区分目标磁盘布局和当前服务启动入口；旧面板从归档存在推导“当前进程仍加载归档”的措辞已纠正。诊断不返回完整命令行或环境变量。

## #19 结论的边界

隔离目录中可复现：存在 app.asar 和解包目录时，原有 sealedAsarHandoff 在 Web surface 返回 null，而 Desktop surface 返回该归档。它与报告中的 Web 上下文线索一致，但不能证明报告者实际运行的完整调用链。测试未启动退出/换包助手、未移动归档。

同一个磁盘布局也可能对应 archive_entry、unpacked_entry 或 unknown_runtime；归档被移走后，原进程入口仍可指向归档。面板和 Agent 现在必须分别看证据，不能把写盘计数视为运行时加载证明。

**#19 保持开放；本版不宣称修好了完整换包流程。** 现有换包助手、重启调度、宿主补丁、提示词、预设策略和更新偏好均未改变。
