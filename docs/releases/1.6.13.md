# Purge Community 1.6.13 验收记录

## 问题与修复

DSH Desktop 0.2.1-rc.2 的 tool-subagent 拒绝旧 toolFilter 参数。一份没有自动管理标记的旧 unrestricted 文件被更新器正确保留，却没有迁移到新注册协议，于是出现真实的预设加载失败。

本版不覆盖自定义 YAML。注册前先将原始 agent.cordis.yml / preset.yml 保存为私有内容寻址备份，带 SHA256 清单；再在内存中将可表示的 spawn deny 策略转换为原生子预设和 agentPreset 引用。父预设只替换这一处策略配置，其余提示词、工具行、深度限制、表达式和用户设置完整保留。子预设继承配置，仅排除原 deny 清单中的工具。设置页会多一个供委派使用的「无限制模式 · 子任务」。

当前支持单个 spawn deny 清单；不猜测未知工具、allow、多个策略或已有独立 agentPreset 的含义。此类配置停止并诊断。新安装也保留原来的子任务工具策略。原有 83 条宿主补丁未修改，不自动应用补丁或重启应用。
