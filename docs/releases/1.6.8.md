# 1.6.8 Windows 实机安装验收

环境：真实 Windows 11 专业版，build 26300；官方 DSH Desktop 0.2.1-rc.2 Windows x64。安装包及应用 exe 的 Authenticode 签名有效，签发主体为 DeepSeek。使用独立测试应用目录、DSH_HOME 和 user-data-dir，不含用户账户、凭证或现有业务数据。

## 实机发现的问题

1.6.7 的 PowerShell 入口用 call operator 执行 Desktop exe。该 exe 是 GUI 子系统进程，PowerShell 可以先返回，再执行 finally 删除临时脚本。实测父进程返回成功，子进程稍后报 MODULE_NOT_FOUND。此前 GitHub Windows runner 的普通 Node 控制台替身无法覆盖此差异。

## 修复与回归

- 用 Start-Process 等待该进程完成，读取真实 ExitCode 与 UTF-8 stdout/stderr，再清理临时目录。
- Windows 原生参数使用完整引号规则传递；不经过 shell 拼接命令执行。
- 添加延迟读取脚本的真实 GUI 子系统测试程序，覆盖成功、参数传递和非零退出；在 Windows PowerShell 5.1 / PowerShell 7 运行。该程序只是回归替身，真实 DSH 安装验收另列。

## 已验证范围

- 实际启动官方 Desktop 副本，确认由它创建独立 desktop profile；这里只验证初始化阶段，不以此宣称完整界面验收。普通 CLI 无权创建保留的 desktop profile，不能以手写配置冒充此步骤。
- 修复后的 PowerShell 入口，使用真实 Desktop Electron 和自带 CLI，完成公开发行包 SHA256 校验、安装、快照和回滚。
- 现有测试提示词保留；备份后再修改提示词，回滚插件后仍保留后来的内容。
- 测试不自动应用宿主补丁，不重启用户已有 DSH，不更改既有生图服务与网络代理。

完整 Windows UI、账号登录与全部宿主补丁功能未在此项安装验收中宣称通过。此记录不包含主机地址、真实用户名、账户文件或私有路径。
